This program writes a single original one-line roast of a smart fridge to `/output/entry.txt`. The fridge body-shames its owner for wanting a snack — then gets undercut by its own broken ice maker, the one job a fridge is actually for.

## Run

```sh
node main.ts
```

Requires Node 22. No dependencies, no network access.
